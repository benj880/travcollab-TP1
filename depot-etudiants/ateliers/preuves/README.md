# Journal des preuves

Une trace par TP dans ateliers/preuves/. Remplacer les champs à compléter, ajouter des liens ou des fichiers relatifs et identifier les auteurs. Les journaux vides ne constituent pas des preuves.

Chaque étudiant doit avoir au moins une hypothèse et un test expliqués, une PR de code, une PR documentaire, une revue argumentée et une prise de parole repérable. Les huit TP produisent huit restitutions collectives courtes.
