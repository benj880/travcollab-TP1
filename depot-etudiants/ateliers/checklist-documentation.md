# Contrôle documentaire

- README : objectif, prérequis, préparation, commandes exécutables, résultats attendus et point d'entrée des documents.
- Architecture : responsabilités des fichiers, circulation des données, dépendances et au moins deux limites.
- Guide technique : reproduction depuis un clone propre ; test, génération, ouverture et au moins deux diagnostics d'erreur.
- ADR : contexte, au moins deux options, décision, conséquence et lien avec un test.
- Changelog : version, comportements modifiés, liens réels des PR et limites restantes.
- Docstrings : entrées, sorties, erreurs, cas limite et cohérence avec les tests.
- Rapport : sources complètes, code cohérent, résultat réel des tests et révision expliquée.

Indiquer le nom du lecteur, le commit examiné et les commandes réellement exécutées. Retirer les TODO avant livraison. Ces critères nécessitent une lecture : le générateur n'évalue pas leur qualité.
